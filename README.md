# sinkfile

Sink CSV/TSV file tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/sinkfile/

## Install / run

```bash
git clone https://github.com/theworker02/sinkfile.git
cd sinkfile
node src/cli.js
node --test
```
